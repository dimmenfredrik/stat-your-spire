# Stat Your Spire (browser version)

Slay the Spire 2 run analytics that run entirely in your browser. Pick your `history` folder
(`%APPDATA%\SlayTheSpire2\steam\<steam id>\profile1\saves\history`) and the page works out your habits, enemies, card
performance, best builds and run stories. Nothing is uploaded; the files are only read inside the page.

The analysis is the same Python code as the downloadable version, run in the browser with Pyodide.
Pictures and exact card numbers are optional: the card-pictures button builds them once, in your browser, from your own copy of the game.
Source and the downloadable version: https://github.com/dimmenfredrik/stat-your-spire
Unofficial fan tool, not affiliated with Mega Crit.
