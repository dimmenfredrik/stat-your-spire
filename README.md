# STS2 Coach (browser version)

Slay the Spire 2 run analytics that run entirely in your browser. Pick your `history` folder
(`%APPDATA%\SlayTheSpire2\steam\<steam id>\profile1\saves\history`) and the page works out your habits, card
performance, danger list and run stories. Nothing is uploaded; the files are only read inside the page.

The analysis is the same Python code as the downloadable version, run in the browser with Pyodide.
Card pictures and exact card numbers are only in the downloadable version (they are built from the player's own game files).
Source and the downloadable version: https://github.com/dimmenfredrik/sts2-coach
Unofficial fan tool, not affiliated with Mega Crit.
